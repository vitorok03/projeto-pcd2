# Como usar este vault

1. No Obsidian: **Abrir pasta como cofre** e escolha a pasta `Soja-Clima-Vault`.
2. Instale o plugin comunitário **Dataview** (usado em [[Painel]]). O Mermaid já vem no Obsidian.
3. Cada nota tem a propriedade `fonte`:
   - `conversa`: documentado a partir das decisões e problemas do projeto
   - `readme`: confirmado no README do repositório
   - `codigo`: confirmado lendo o código (solo, pacifico, merge, main.ipynb)
   - `a-confirmar`: **não foi verificado no código**. Confira e atualize.
4. Convenção de ids: **D** = decisão, **P** = problema, **Q** = questão em aberto.
5. Nunca apague uma decisão revertida: mude `status` para `substituida` e linke a nova.
6. Ao resolver algo ou decidir algo, crie a nota na hora (modelos em `Templates/`).
